# Trace Env Landing Page

Production-ready Next.js landing page for Trace Env.

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS 4

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env.local` and set values for your environment
3. Run the app:
   `npm run dev`

## Production

1. Build the app:
   `npm run build`
2. Start the server:
   `npm run start`
